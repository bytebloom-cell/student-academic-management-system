# Student Academic Management System

A Python project built using Object-Oriented Programming (OOP).

## Features
- Add student records
- Display all students
- Search students by ID or name
- Update CGPA
- Delete student records
- Rank students based on CGPA
- Calculate academic statistics
- Save student data using JSON

## OOP Concepts
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Technologies Used
- Python
- JSON
- Object-Oriented Programming

## How to Run
Run the Python file using:

```bash
python student_academic_management_system.py
```

## Purpose
Created as a Python OOP project for learning and interview preparation.
